# ATLAS Rail Operations Viewer

Static, client-side viewer for rail operations stringlines, traffic density, and passenger statistics.

The viewer runs in the browser and loads the selected source data locally. Raw CSV, spreadsheet, PDF, and presentation files are intentionally excluded from this repository; they are not required for the published webpage.

## GitHub Pages

The included workflow deploys the contents of `main` to GitHub Pages after each push. Once Pages is enabled for the repository, the site will be available at:

`https://lookarail.github.io/ATLAS/`
